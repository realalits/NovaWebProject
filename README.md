# Nova - Responsive Landing Page

## Week 1 Task: Responsive Landing Page Development

This project is a responsive landing page created using:

- Semantic HTML5
- Modern CSS3
- Flexbox
- CSS Grid
- Media Queries
- Vanilla JavaScript

## Files

- `index.html` - Main webpage structure
- `style.css` - Responsive styling and layout
- `script.js` - Mobile menu and navigation interactions

## Features

1. Responsive header and navigation
2. Mobile hamburger menu
3. Hero section with CTA buttons
4. Dashboard-style CSS illustration
5. Feature cards
6. Responsive About section
7. Call-to-action section
8. Responsive footer
9. Smooth scrolling
10. Active navigation highlighting
11. Automatic copyright year
12. Mobile, tablet and desktop layouts

## How to Run

No installation is required.

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For development, you can also use VS Code with the Live Server extension.

## Responsive Breakpoints

- Desktop: above 900px
- Tablet: 701px - 900px
- Mobile: up to 700px
- Small phones: up to 420px

## Browser Testing

The page is designed to work with modern browsers such as:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari
